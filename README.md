# Bereket Kinfe - Personal Portfolio

My personal website. Built to show who I am, what I've worked on, and how to reach me.

Live at **[bereketkinfe.pro.et](https://bereketkinfe.pro.et)**

## Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Motion (Framer Motion)
- **Email**: Resend
- **Fonts**: Instrument Sans, Plus Jakarta Sans, JetBrains Mono

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
